# EDITOR.md — ブラウザ上の編集(段階 1：文字の編集、段階 2：スライドの操作)

デッキをブラウザで開いたまま、文字を直し、スライドを足したり並べ替えたりして、元のファイルに保存する。
PowerPoint の「ホーム」タブの文字まわりとスライドまわり、左のスライド一覧に相当する。

## 起動

- 手元の `index.html` をそのまま開くと、編集画面(PowerPoint の標準表示)で開く
  - 発表の表示で開くには `?present` を付ける(例 `index.html?present`)。デッキ側で `PPShell.init({ editByDefault: false })` にすると既定を発表の表示に戻せる
  - verify・PDF 書き出しなどの自動操作、スピーカービューの中、印刷用の表示、http(s) で配信したときは、従来どおり発表の表示
- 発表の表示からは、ドックの鉛筆ボタン、**E** キー、または URL に `?edit`
- リボン右の **スライドショー** で、今のスライドから全画面で発表する。全画面を抜ける(Esc)と編集画面に戻る。未保存の変更はそのまま残る
- **閲覧表示** で編集画面を閉じる(未保存があれば確認)
- 単一 HTML に束ねた配布物(bundle)では出ない(配布物は編集させない)
- 保存には Chrome か Edge が必要(File System Access API)。表示と編集だけなら他のブラウザでも動く

## できること

| グループ | 操作 |
|---|---|
| ファイル | 保存(⌘S / Ctrl+S) |
| 元に戻す | 元に戻す(⌘Z)・やり直し(⌘⇧Z / Ctrl+Y)。文字の編集とスライドの操作を、操作した順に 200 回まで戻す |
| スライド | 新しいスライド(レイアウトの型 / 白紙)・複製・削除・リセット(保存した状態に戻す)・前へ / 後ろへ移動・セクション |
| クリップボード | 切り取り・コピー・貼り付け(書式なし)・書式のコピー |
| フォント | 太字(⌘B)・斜体(⌘I)・下線(⌘U)・取り消し線・上付き・下付き・文字を大きく / 小さく(2px 刻み)・文字の色・蛍光ペン・書式のクリア |
| 段落 | 箇条書き・段落番号・インデント・行間・左 / 中央 / 右 / 両端揃え |
| 移動 | 前後のスライドと現在位置 |
| 挿入 | 図形(33 種)・線 / 矢印 / カギ線・テキストボックス・画像(ファイル / 貼り付け / ドラッグ)・表・リンク |
| 図形の書式 | 塗りつぶし・枠線(色・太さ・破線 / 点線・矢印)・影・透明度・グラデーション・図形の文字の色・上下の配置・図形の変更 |
| 配置 | 重なり順(最前面 / 前面 / 背面 / 最背面)・グループ化 / 解除・回転(ハンドル / 90°)・上下 / 左右反転・位置とサイズ(数値)・複製 |

- テーマの部品(カード・帯など)で直せるのは文字と位置・大きさ。構造は壊れない。新しい図形・画像・表は「挿入」から足す(下の「図形・画像・表の挿入」)
- 編集中は段階表示(fragment)を全部表示する
- Esc で文字の編集を抜ける(部品を選んでいれば選択を外す)。編集画面を閉じるのはリボン右の「閲覧表示」
- 貼り付けは常に書式なし(ほかの資料の書式を持ち込まない)

## 画面の配置

PowerPoint for the web の標準表示と同じ組み方。

- 上：タイトルの行(資料名・保存の状態・保存ボタン)、タブ(ファイル・ホーム・挿入・配置・表示。右にスライドショーと閲覧表示)、1 行のリボン
  - 部品を選んでいる間は「図形の書式」、表のセルにカーソルがある間は「テーブル」のタブが出る(PowerPoint のコンテキスト タブ)
  - リボンは幅に収まらない分を後ろのグループから「…」に入れる
- 左にスライド一覧、右に編集中のスライド、その下にノート
- 下：状態の帯(スライドの番号・ページのファイル名・ノートの表示 / 非表示)

- 一覧はスライドの縮小表示(テーマの見た目のまま)。直した中身は少し遅れて縮小表示にも反映される
- ノート欄は今のスライドの `aside.notes` をそのまま直す。Enter は改行(`<br>`)。空にすると `aside.notes` ごと外す。元に戻す・保存はスライドの文字と同じ扱い
- 一覧とスライドの境目を左右に、スライドとノートの境目を上下にドラッグすると大きさが変わる。ノートはリボン右の「ノート」か、境目のダブルクリックで表示 / 非表示
- 一覧の幅・ノートの高さ・表示 / 非表示はブラウザが覚える(localStorage の `pp-editor-layout`)

## 名前

リボンの「ファイル › 名前」(またはリボン右の資料名をクリック、一覧のファイル名をダブルクリック)で直す。保存するとファイルに書き込む。元に戻すもできる。

| 名前 | ページ単位のデッキ | 通常のデッキ |
|---|---|---|
| 資料のタイトル | `decks/<冊>.json` の `title` | `index.html` の `<title>`(と `PPShell.init({ title })`) |
| 配るときのファイル名 | `decks/<冊>.json` の `dist`(単一 HTML・PDF の名前) | なし |
| 冊の名前 | `decks/<冊>.json` のファイル名(出力のフォルダ名にもなる。古い出力のフォルダは残る) | なし(フォルダはファインダーで) |
| ページのファイル名 | `pages/<キー>.html` を付け替え、そのページを使う**全部の冊**の並びも書き換える | なし |

- 付け替え先にすでに同じ名前のファイルがあるときは保存しない(上書きしない)
- 名前は英数字と `. _ -`。配るときのファイル名は日本語も使える(`\ / : * ? " < > |` 以外)

## 部品の移動と大きさ(段階 3 の一部)

- スライド上の部品(カード・帯・画像・図・文字の枠)をクリックすると青い枠で選ばれる
  - 文字のない所(カードの余白など)を押してそのままドラッグすると移動。Shift を押しながらで縦か横だけ
  - 文字の上を押すと、その文字の枠を選んで文字の編集に入る。文字の枠を動かすときは青い枠の縁をドラッグ
  - 選んである部品の中をもう一度押すと 1 段内側の部品、リボンの「配置 › 外側を選ぶ」で 1 段外側
- **複数選択**：Shift(または ⌘ / Ctrl)+クリックで足す・外す。スライドの何もない所(スライドの外の灰色の所からでも)をドラッグすると、囲んだ部品をまとめて選ぶ。⌘A でそのスライドの部品を全部
  - 選んだ部品のどれかをドラッグすると、まとめて動く。動かさずにクリックすると、その部品だけの選択になる
- **ガイド線と吸着**：動かしている部品の端・中央が、スライドの端・中央やほかの部品の端・中央に近づく(6px 以内)と吸い付き、赤紫の線が出る(スライドの中央は破線)。大きさを変えるときは動かしている辺が吸い付く。Alt(Option)を押している間は吸い付かない
- **揃える**(配置 › 揃える ▾)：左・左右中央・右・上・上下中央・下揃え、左右 / 上下に等間隔(3 つ以上)。2 つ以上選んでいれば選んだ範囲に、1 つならスライドに合わせる
- 表の中を押すと、まず表ごと選ぶ(文字の上ならそのセルの文字も直せる)。もう一度押すとセル。行は単独では選ばない
- 四隅と辺の白い四角をドラッグで大きさを変える(表は行の高さ・列の幅が広がる)。Shift を押しながら角を引くと縦横の比を保つ
- 部品を選んで(文字は選ばずに)A+ / A− を押すと、その中の文字を全部同じ割合で大きく / 小さくする。「位置と大きさを元に戻す」で文字の大きさも戻る
- 矢印キーで 1px、Shift+矢印で 10px 動かす。Delete / Backspace で部品を削除。Esc で選択を外す(文字の編集中は文字が優先)
- 「配置 › 位置と大きさを元に戻す」で、その部品の移動・大きさの指定を外す
- 保存されるのはその要素のインライン style(`translate`、`width`、`height`、flex の中では `flex: none`)。周りの部品の並び(レイアウトの流れ)は変わらない
- 元に戻す・保存は文字の編集と同じ扱い

## 図形・画像・表の挿入(挿入タブ・図形の書式タブ)

PowerPoint の「挿入」「図形の書式」「テーブル レイアウト」にあたる。ホームのリボンにも「図形 ▾・テキストボックス・塗りつぶし ▾・枠線 ▾・重なり順 ▾」がある。

### 挿入

- **図形 ▾**：一覧から選び、スライドの上をドラッグして描く(Shift で縦横の比をそろえる)。クリックだけなら標準の大きさ。Esc でやめる
  - 線：直線・矢印・両矢印・カギ線矢印(始点から終点へドラッグ。Shift で 45° ごと)
  - 四角形(長方形・角丸・端子)、基本図形(楕円・三角形・直角三角形・ひし形・平行四辺形・台形・五角形・六角形・八角形・十字・円柱・星)、
    ブロック矢印(上下左右・左右・上下・ホームベース・山形)、フローチャート(処理・判断・書類・磁気ディスク)、吹き出し(四角形・角丸)
- **テキストボックス**：置く所をクリック(ドラッグで幅を決める)。高さは中身に合わせて伸びる
- **画像**：ファイルを選ぶ。コピーした画像を ⌘V、画像ファイルをスライドにドラッグしても入る。長い辺 1920px を超える画像は縮めて、HTML に埋め込む(`data:` URL)
- **表 ▾**:行と列の数(最大 8 × 10)を選ぶ。1 行目は見出し、本文は縞模様
- **リンク**：選んだ文字に URL(`https://` `http://` `mailto:` だけ)を付ける / 外す
- 文字を打っていないときに ⌘V でほかのアプリの文字を貼ると、テキストボックスになる

### 図形を選んで直す

- クリックで選ぶ。そのまま文字を打つと図形の文字になる(Enter / F2 で文字の終わりから。ダブルクリックでその位置から)。選んである図形の文字の上をもう一度押しても文字の編集
- テキストボックスと表は、1 回目のクリックから文字を直せる(動かすときは青い枠の縁をドラッグ)
- 上の丸をドラッグで回転(Shift で 15° ごと。0・90・180° の近くでは吸い付く)。回転していても四隅・辺で大きさを変えられる
- 線は両端の丸をドラッグ。ほかの部品の端・中央に吸い付く(つなぎやすい)。Shift で 45° ごと
- 画像の角は縦横の比を保つ(Shift で自由に)。ほかの部品は Shift で比を保つ
- グループは 1 回目でグループ全体、もう一度押すと中の部品。グループの大きさを変えると中の部品も同じ割合で変わる

### 図形の書式

| ボタン | 中身 |
|---|---|
| 塗りつぶし ▾ | テーマの色(`--pp-ed-c*`)・文字の色 / 地の色(テーマ)・白・黒・塗りつぶしなし・その他の色 |
| 枠線 ▾ | 色・なし、太さ(0.75〜6 pt)、実線 / 破線 / 点線、線なら矢印(終点・始点・両端・開いた矢印・丸) |
| 効果 ▾ | 影、透明度(図形は塗りだけ、画像などは部品ごと)、グラデーション(左 → 右 / 上 → 下。塗りの色を白に寄せた色から) |
| 文字の色 ▾ / 上下の配置 ▾ | 図形の中の文字の色(既定は塗りの明るさに合わせて白か濃い色)、上 / 中央 / 下揃え |
| 図形の変更 ▾ | 形だけを替える(色・文字はそのまま) |
| 前面へ ▾ / 背面へ ▾ | 最前面・前面・背面・最背面。**最背面はテーマの部品(文字・カード)より後ろ**。重なり順を変えられるのは挿入した部品だけ |
| グループ ▾ / 回転 ▾ | グループ化(⌘G)・解除(⌘⇧G)。右 / 左へ 90°・上下 / 左右反転・回転を元に戻す |
| 位置とサイズ | 横・縦の位置、幅・高さ、回転を数値で(スライドの px。縦横比の固定) |

- テーマの部品(カードなど)を選んで使うと、塗りは背景色、枠線は `border`、影は `box-shadow` として付く
- テーマの色は `var(--pp-ed-cN)` のまま保存するので、ライト / ダークを替えても追従する。「その他の色」は色の値をそのまま書く(モードを替えても変わらない。色の意味をそろえるため、まずテーマの色を使う)

### テーブル(表のセルにカーソルがあるとき)

上 / 下に行、左 / 右に列を挿入、行 / 列 / 表の削除、見出しの行のオン / オフ、縞模様のオン / オフ。セルの中の Enter は改行。
テーマの表(HTML で書いた表)でも行・列の挿入と削除は使える(結合したセルは考えない)。

### キー

| キー | 操作 |
|---|---|
| ⌘C / ⌘X / ⌘V | 部品を選んでいるとき(文字を打っていないとき)は部品ごとコピー / 切り取り / 貼り付け(同じスライドでは 20px ずらす) |
| ⌘D | 部品の複製 |
| ⌘G / ⌘⇧G | グループ化 / 解除 |
| ⌘] / ⌘[ | 前面へ / 背面へ(Shift で最前面 / 最背面) |
| 文字キー・Enter・F2 | 選んだ図形の文字の編集(文字キーは中身を置き換える) |
| Esc | 描くのをやめる → 文字の編集を抜ける → 選択を外す |

### HTML の形(手で書かない)

挿入した部品は `<section>` 直下(またはグループの中)に置く `.pp-obj`。位置は `left` / `top`(1280 × 720 の座標)、大きさは `width` / `height`。

```html
<div class="pp-obj pp-shape" data-shape="chevron" style="left: 100px; top: 420px; width: 240px; height: 80px; --sh-fill: var(--pp-ed-c1);">
  <svg class="pp-sh-g" width="240" height="80" viewBox="0 0 240 80" aria-hidden="true"><g><path class="pp-sh-p" d="…"/></g></svg>
  <div class="pp-sh-t">文字</div>
</div>
<div class="pp-obj pp-line" data-shape="line|elbow" data-he="tri" data-flip="v" style="…">…</div>   <!-- 枠の左上 → 右下に引く。data-flip で向き -->
<div class="pp-obj pp-shape pp-tb" data-shape="rect" style="…">…</div>                              <!-- テキストボックス -->
<img class="pp-obj pp-pic" src="data:…" style="…">  <div class="pp-obj pp-tblw"><table class="pp-tbl">…</table></div>  <div class="pp-obj pp-group">…</div>
```

- `data-shape` は PowerPoint の図形の名前(`prstGeom`)。輪郭の SVG はエディターが大きさに合わせて作り、HTML に残す(配布物・PDF は JS なしで描ける)。大きさを手で変えると輪郭がずれるので、直すのはエディターで
- 色は CSS 変数:`--sh-fill`(塗り)・`--sh-fo`(塗りの不透明度)・`--sh-line`(枠線・線)・`--sh-lw`(太さ)・`--sh-tc`(文字)。ほかに `data-dash`・`data-grad`・`data-valign`・`data-hs` / `data-he`(線の端)・`.pp-shadow`・`.pp-back`(最背面)。見た目は `runtime/shell.css`
- verify:図形の文字は図形の塗りを地としてコントラストを測る。線と図形の輪郭は重なりの判定から外す(図形の文字は判定する)
- 直せる PPTX(`export-pptx-editable.mjs`)では PowerPoint の図形・線(矢印付き)・表としてそのまま入る。グラデーションは塗りの色の単色、グループは中の部品に分かれる。PowerPoint は図形ごとに文字の入る範囲が狭い(ひし形・三角形など)ので、折り返しが増えることがある

## スライドの操作(段階 2)

- 左のスライド一覧：クリックで移動、ドラッグで並べ替え。ページ単位のデッキではセクションの見出し(目次の区切り)も出る。未保存のスライドには番号の下に ● が付く
- 新しいスライドは今のスライドの後ろに入る(今のスライドと同じセクション)。型はデッキの `<template data-pp-layout="名前">` から選ぶ。型がなければ白紙(タイトルと本文)
- 複製はそのスライドを丸ごと写す。ページ単位のデッキでは新しいキー(`<元のキー>-copy-<日付>-<連番>`、型からは `<接頭辞>.new-<日付>-<連番>`)を付け、保存時に新しいファイルを作る
- 削除：ページ単位のデッキでは**その冊から外すだけ**で、ページのファイルは消さない(ほかの冊で使っていることがあるため)
- リセット：そのスライドを、最後に保存した状態(または開いた時の状態)に戻す。今回追加したスライドには戻す元がない
- 自動で作るページ(`data-page="(…)"`、例：目次)は直せない・複製できない。目次は保存後の組み立てで作り直される
- セクション(ページ単位のデッキだけ)：今のスライドからセクションを始める・名前を変える・区切りを外す。冊の並びの `@toc 部|名前` になる

### ページ単位のデッキの印

組み立てスクリプトが次を埋め込むと、スライドの操作を冊の並びとして保存できる。

```html
<meta name="pp-deck" content="冊の名前">
<script type="application/json" id="pp-deck">{"title": "…", "pages": ["キー", "@toc-page", "@toc 部|名前", …]}</script>
<template data-pp-layout="タイトルと表"><section class="…">…</section></template>
```

- `pages` の `@toc-page` は目次のページ、`@toc 部|名前` はセクションの区切り(スライドではない)。それ以外はページのキー
- 並びとスライドの `data-page` が合わないときは、ページ単位の保存を使わない(コンソールに警告)

## 色はテーマのパレットだけ(文字の色)

文字の色は自由な色ではなく、テーマが定義する `--pp-ed-c1`〜`--pp-ed-c6`(表示名 `--pp-ed-cN-label`)から選ぶ。
デッキ全体で色の意味をそろえるため(CONTENT.md「色は識別の意味に割り当てる」)。
付くのはクラス `.pp-c1`〜`.pp-c6`・`.pp-hl`(蛍光ペン)で、見た目は `runtime/shell.css` が定義する(配布物・PDF でも同じ)。
テーマを追加するときは vars に `--pp-ed-c*` を定義する(aws・sumi は定義済み)。

## 保存先

| デッキの作り | 保存先 |
|---|---|
| ページ単位(`data-page="キー"` と上の印) | 初回に選ぶ **webdeck フォルダ**(`src` と各冊のフォルダが入っている所)の `src/pages/<キー>.html`、並び・名前を変えたら `src/decks/<冊>.json`、さらに**開いている冊の `index.html`** も今の中身に書き換える(再読み込みしても直した内容が出る)。`src` を選んだときはページと並びだけ |
| 通常(index.html 1 枚) | 初回に選んだ `index.html`。文字だけなら該当の `<section>` だけ、スライドの操作があれば `.slides` の中を丸ごと書き換える(`.slides` の外は変えない) |

- 保存先の選択はブラウザが覚える(次回は許可の確認だけ)
- 直してから元に戻したスライド、元の並びに戻した冊の並びは書かない
- 保存している間に直したものは未保存のまま残り、次の保存で書く

## 自動保存

タイトルの行の「自動保存」スイッチ(既定はオン。ブラウザが覚える)。オンのときは、直してから 2.5 秒たつと自動で保存する(ドラッグ中・日本語の変換中は待つ)。

- 保存先をまだ選んでいないとき、または開き直して保存先の許可が切れているときは「待機中」になる。「保存」を一度押す(保存先を選ぶ・許可する)と、以後は自動で保存する
- 状態はタイトルの行に出る(未保存 / 保存しています… / 自動保存しました 14:05)

## 書き出し(ファイル タブ)

- **PDF に書き出す**：保存してから、このデッキを印刷の表示で別の窓に開き、印刷の画面を出す。送り先で「PDF として保存」を選ぶ。ページ単位のデッキは、webdeck フォルダを保存先にしていれば直した内容がそのまま入る
- **PowerPoint に書き出す**：手元のターミナルで実行するコマンドを出す(ブラウザの中からは、テーマの画像やフォントを読み込めないため)
  - 直せる形：`tools/export-pptx-editable.mjs`(ページ単位のデッキは `assemble.py <冊> --pptx`)。文字はテキストボックス、背景・枠線は図形、画像・SVG は画像、ノートはスピーカーノート。位置はほぼ合うが、折り返しやグラデーション・影は少し変わる
  - 見た目を完全に合わせた形：`tools/export-pptx.mjs`(各スライドを画像で貼る。直せない)
- Reveal が表示のために付ける属性・クラス(`present`、`aria-hidden`、`data-fragment-index` など)と編集用の属性は保存前に外す
- 組み立て時にパスを書き換えるデッキは `<meta name="pp-subst" content="置き換え後=>元の書き方">` を置くと、保存時に元の書き方へ戻す(`||` 区切りで複数)

## 保存の後

保存しても、配布物(`out/`)は古いまま。**直したら verify と書き出しをやり直す**(SKILL.md 手順 6・7)。
ページ単位のデッキは、組み立てスクリプトで各冊に反映してから verify する(目次のページ番号もここで更新される)。

## 指摘(Orca など)から元のファイルを探す

- 今のスライドのページ名を URL の `?page=<キー>` に入れる(発表の表示でも)。Orca の Design Feedback は URL の `#/番号` を落とすため
- `node tools/find-page.mjs "<URL>" --selector="<指定>" --text="<文字>"` で、元のページのファイルと行を出す(URL のページを最初に。共有している冊も出す)
- どのページにも無い文字は、エディターの画面など、スライドの外の部分

## 編集用の 1 ファイル(PowerPoint のファイルのように持ち運ぶ)

- `node tools/bundle.mjs <deckDir> --editable`(ページ単位のデッキは `assemble.py <冊> --single`)で、画像・フォント・テーマ・エディターを全部入れた 1 ファイルの HTML(`out/<名前>-edit.html` / `out/<配る名前>_編集用.html`)を作る
- 開くと編集画面になり、**そのファイルに上書き保存**(自動保存も)できる。初回の保存で、そのファイル自身を選ぶ。人に渡して直してもらうこともできる
- 直したファイルを正本に戻す：`node tools/import-single.mjs <ファイル> <src フォルダ>`(何が変わるかを出す)→ `--write` で書き込む → `assemble.py` で組み立て
  - 埋め込んだ画像は、ファイルに記録した元の場所(`<script id="pp-assets">`)に戻す。1 ファイルの中で足した画像は `src/assets/added-*.png` に書き出す
  - ほかの冊でも使っているページは、その冊も一覧に出す(戻すと反映される)
- 埋め込み PDF とスピーカービューのサムネイルは入れない(直すと古くなるため)。PDF は Chrome で「PDF に書き出す」、PowerPoint は正本に戻してから
